# ![](dotnetimages/collapse.gif)Remarks

This interface:

* extends [IEdmVault18](EPDM.Interop.epdm~EPDM.Interop.epdm.IEdmVault18.html) by providing the ability to:
  + Call the Set Revision command to update a revision table in a SOLIDWORKS drawing in this vault.+ Copy an assembly tree of referenced parts and drawings to a destination folder.

* is extended by [IEdmVault20](EPDM.Interop.epdm~EPDM.Interop.epdm.IEdmVault20.html).
