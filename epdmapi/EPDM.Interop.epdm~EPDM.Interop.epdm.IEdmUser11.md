# ![](dotnetimages/collapse.gif)Remarks

This interface extends [IEdmUser10](EPDM.Interop.epdm~EPDM.Interop.epdm.IEdmUser10.html) by providing the ability to specify these user settings:

* Automatically delete local read-only files in File Explorer that are not part of the file vault.* Always work with the latest version of files.* Auto-select reference files to get latest when checking out.
