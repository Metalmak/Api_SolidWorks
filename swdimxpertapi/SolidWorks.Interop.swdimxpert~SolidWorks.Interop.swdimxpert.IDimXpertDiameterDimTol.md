Use the Dimension Size icon on the DimXpert toolbar to create diameter dimensions on closed curved faces.

You can access more general dimension tolerance information using [IDimXpertDimensionTolerance](SOLIDWORKS.Interop.swdimxpert~SOLIDWORKS.Interop.swdimxpert.IDimXpertDimensionTolerance.html).
