# Body2::GetMaterialIdName

This method is obsolete and has been superseded
by Body2::GetMaterialIdName2.

Description

This method gets the material ID name for this body. This ID is not
visible to the user.

Syntax (OLE Automation)

retval = Body2.GetMaterialIdName ()

| Return: | (BSTR) retval | Material ID name |

Syntax (COM)

status = Body2->GetMaterialIdName
( &retval )

| Output: | (BSTR) retval | Material ID name |
| Return: | (HRESULT)status | S\_OK if successful |
