# PartDoc::SaveToFile

This method is obsolete and has been superseded
by PartDoc::SaveToFile2.

Description

This method saves the selected
surfaces or solid bodies in the Surface
Bodies or Solid
Bodies folders or sub-folders
to part files.

Syntax (OLE Automation)

void = PartDoc.SaveToFile ()

Syntax (COM)

status = PartDoc->SaveToFile ( )

|  |  |  |
| --- | --- | --- |
| Return: | (HRESULT) status | S\_OK if successful |
