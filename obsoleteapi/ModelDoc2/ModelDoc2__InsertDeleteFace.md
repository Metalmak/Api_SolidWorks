# ModelDoc2::InsertDeleteFace

This method is obsolete and has been superseded
by ModelDoc2::InsertDeleteFace2.

Description

This method deletes the selected faces of a
surface.

Syntax (OLE Automation)

void ModelDoc2.InsertDeleteFace ( )

Syntax (COM)

status = ModelDoc2->InsertDeleteFace ( )

| Return: | (HRESULT) status | S\_OK if successful |

Remarks

This method only operates on selected faces of
surface models.
