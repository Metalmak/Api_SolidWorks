# PropertyManagerPage2Handler4::OnNextPage

This method is obsolete and has been superseded
by PropertyManagerPage2Handler5::OnNextPage.

Description

This method is called when
a user clicks the Next button on the PropertyManager.

Syntax (OLE Automation)

retval = PropertyManagerPage2Handler4.OnNextPage
( )

#

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the next page displays successfully, FALSE if not |

#

Syntax (COM)

status = PropertyManagerPage2Handler4->OnNextPage
( &retval )

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the next page displays successfully, FALSE if not |
| Return: | (HRESULT) status | S\_OK if successful |

#
