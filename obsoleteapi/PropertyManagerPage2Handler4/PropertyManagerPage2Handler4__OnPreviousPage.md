# PropertyManagerPage2Handler4::OnPreviousPage

This method is obsolete and has been superseded
by PropertyManagerPage2Handler5::OnPreviousPage.

Description

This method is called when
a user clicks the Back button on this PropertyManager.

Syntax (OLE Automation)

retval = PropertyManagerPage2Handler4.OnPreviousPage
( )

#

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the previous page displays successfully, FALSE if not |

#

Syntax (COM)

status = PropertyManagerPage2Handler4->OnPreviousPage
( &retval )

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the previous page displays successfully, FALSE if not |
| Return: | (HRESULT) status | S\_OK if successful |
