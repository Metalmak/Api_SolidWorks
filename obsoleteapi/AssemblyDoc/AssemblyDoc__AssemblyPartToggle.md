# AssemblyDoc::AssemblyPartToggle

This method is obsolete and has been superseded
by AssemblyDoc::EditAssembly
and AssemblyDoc::EditPart2.

Description

This
method toggles between in-context editing of the selected assembly component
and editing the assembly.

void
