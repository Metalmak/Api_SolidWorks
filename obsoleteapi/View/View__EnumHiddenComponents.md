# View::EnumHiddenComponents

This method is obsolete and has been superseded
by View::EnumHiddenComponents2.

Description

This method gets the hidden components in this
drawing view.

Syntax (OLE Automation)

See View::GetHiddenComponents.

Syntax (COM)

status = View->EnumHiddenComponents ( &hiddenComps
)

|  |  |  |
| --- | --- | --- |
| Output: | (LPENUMCOMPONENTS) hiddenComps | Pointer to the EnumComponents object |
| Return: | (HRESULT) status | S\_OK if successful |
