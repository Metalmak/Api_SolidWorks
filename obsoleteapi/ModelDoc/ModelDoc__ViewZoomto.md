# ModelDoc::ViewZoomto

This method is obsolete
and has been superseded by ModelDoc2::ViewZoomto.

Description

This method zooms the view to the selected box. See also ModelDoc::ViewZoomTo2,
which allows you to zoom to an X,Y,Z boxed location.

Syntax (OLE Automation)

void ModelDoc.ViewZoomto ()

Syntax (COM)

status = ModelDoc->ViewZoomto (
)
