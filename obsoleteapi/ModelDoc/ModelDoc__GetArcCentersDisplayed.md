# ModelDoc::GetArcCentersDisplayed

This
method is obsolete and has been superseded by ModelDoc2::GetArcCentersDisplayed.

Description

This method gets
the display setting for the arc centers.

retval = ModelDoc.GetArcCentersDisplayed
()

|  |  |  |
| --- | --- | --- |

|  |  |  |
