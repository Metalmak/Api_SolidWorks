# ModelDoc::InspectCurvature

This
method is obsolete and has been superseded by ModelDoc2::InspectCurvature.

Description

This method activates the inspection of curvature
display on the selected sketch segment

Syntax (OLE Automation)

void ModelDoc.InspectCurvature ( )

Syntax (COM)

status = ModelDoc->InspectCurvature ( )

|  |  |  |
| --- | --- | --- |
| Return: | (HRESULT) status | S\_OK if successful |

Remarks

See ModelDoc::RemoveInspectCurvature to deactivate
the curvature display.
