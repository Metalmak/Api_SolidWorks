# ModelDoc::RemoveInspectCurvature

This
method is obsolete and has been superseded by ModelDoc2::RemoveInspectCurvature.

Description

This method deactivates the inspection of curvature
display on the selected sketch segment.

Syntax (OLE Automation)

void ModelDoc.RemoveInspectCurvature ( )

Syntax (COM)

status = ModelDoc->RemoveInspectCurvature ( )

|  |  |  |
| --- | --- | --- |
| Return: | (HRESULT) status | S\_OK if successful |

Remarks

See ModelDoc::ModelDoc::InspectCurvature to deactivate
the curvature display.
