# ModelDoc::EditSketch

This
method is obsolete and has been superseded by ModelDoc2::EditSketch.

Description

This method edits the currently selected sketch. After the sketch is
in edit mode, you can add or delete geometry from the sketch and perform
other standard sketching operations.

Syntax (OLE Automation)

void ModelDoc.EditSketch ()

Syntax (COM)

status = ModelDoc->EditSketch (
)

|  |  |  |
| --- | --- | --- |
| Return: | (HRESULT) status | S\_OK if successful |
