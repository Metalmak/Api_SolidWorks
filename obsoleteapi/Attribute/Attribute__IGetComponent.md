# Attribute::IGetComponent

This
method is obsolete and has been superseded by Attribute::IGetComponent2.

Description

This method returns the component to which
this attribute is attached.

Syntax (OLE Automation)

Not available.

Syntax (COM)

status = Attribute->IGetComponent ( &retval)

|  |  |  |
| --- | --- | --- |
| Output: | (LPCOMPONENT) retval | Pointer to component object |
| Return: | (HRESULT) status | S\_OK if successful |
