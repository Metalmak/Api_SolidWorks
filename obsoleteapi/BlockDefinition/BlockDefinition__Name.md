# BlockDefinition::Name

This property is obsolete and was not superseded.

Description

This property gets or sets the name of the
block definition.

Syntax (OLE Automation)

Name = BlockDefinition.Name (VB Get property)

BlockDefinition.Name = Name (VB Set property)

Name = BlockDefinition.GetName ( ) (C++ Get property)

BlockDefinition.SetName ( Name ) (C++ Set property)

| Property: | (BSTR) Name | Name of the block definition |

Syntax (COM)

status = BlockDefinition->get\_Name ( &Name
)

status = BlockDefinition->put\_Name ( Name )

| Property: | (BSTR) Name | Name of the block definition |
| Return: | (HRESULT) status | S\_OK if successful |
