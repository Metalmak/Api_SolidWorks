# BlockDefinition::GetNoteCount

This method is obsolete and has been superseded
by SketchBlockDefinition::GetNoteCount.

Description

This method gets the number of notes in the
block definition.

Syntax (OLE Automation)

retval = BlockDefinition.GetNoteCount ( )

#

|  |  |  |
| --- | --- | --- |
| Output: | (long) retval | Number of notes |

#

Syntax (COM)

status = BlockDefinition->GetNoteCount ( &retval
)

|  |  |  |
| --- | --- | --- |
| Output: | (long) retval | Number of notes |
| Return: | (HRESULT) status | S\_OK if successful |
