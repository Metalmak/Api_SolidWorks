# ExtrudeFeatureData Object

This object and its properties and methods are
obsolete and have been superseded by ExtrudeFeatureData2.

|  |  |
| --- | --- |
| ![image\Feature.gif](../image/Feature.gif) | |
|  | ![image\branch1.gif](../image/branch1.gif)![image\ExtrudeFeatureData_h.gif](../image/ExtrudeFeatureData_h.gif) |

Allows access to the data that defines an extrusion
feature. For extrusion features, Feature::GetTypeName returns "Cut",
"Boss", "BossThin", or "CutThin", depending
upon the type of extrusion feature.

Use the Accessors
link above to get a list of functions that return this object.
