# PropertyManagerPage2Handler3::OnHelp

This method is obsolete and has been superseded
by [PropertyManagerPage2Handler4::OnHelp](../PropertyManagerPage2Handler4/PropertyManagerPage2Handler4__OnHelp.htm).

Description

This method is called when
a user clicks the Help button on this PropertyManager.

Syntax (OLE Automation)

retval = PropertyManagerPage2Handler3.OnHelp ( )

#

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the Help file opens successfully, FALSE if not |

#

Syntax (COM)

status = PropertyManagerPage2Handler3->OnHelp
( &retval )

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the Help file opens successfully, FALSE if not |
| Return: | (HRESULT) status | S\_OK if successful |
