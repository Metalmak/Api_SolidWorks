# ComponentMoveNotify - AssemblyDoc Event

This event is obsolete and has been superseded
by ComponentMoveNotify2
- AssemblyDoc Event.

Description

Fired whenever a component
within this assembly moves.

NOTE:
If developing a C++ application, use swAssemblyComponentMoveNotify to
register for this notification.
