# PropertyManagerPage2Handler2 Object

This object is obsolete and has been superseded
by [PropertyManagerPage2Handler3](../PropertyManagerPage2Handler3/PropertyManagerPage2Handler3.htm).

![](../image/PropertyManagerPage2Handler2_h.gif)

Must be implemented by the add-in application to
interact with a PropertyManagerPage2.

For all unimplemented methods of this object, the
add-in application can return E\_NOTIMPL.
