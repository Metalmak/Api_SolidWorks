# PropertyManagerPage2Handler2::OnPreviousPage

This method is obsolete and has been superseded
by [PropertyManagerPage2Handler3::OnPreviousPage](../PropertyManagerPage2Handler3/PropertyManagerPage2Handler3__OnPreviousPage.htm).

Description

This method is called when
the end-user clicks the Back button on this PropertyManager.

Syntax (OLE Automation)

retval = PropertyManagerPage2Handler2.OnPreviousPage
( )

#

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the previous page displays successfully, FALSE if not |

#

Syntax (COM)

status = PropertyManagerPage2Handler2->OnPreviousPage
( &retval )

|  |  |  |
| --- | --- | --- |
| Output: | (VARIANT\_BOOL) retval | TRUE if the previous page displays successfully, FALSE if not |
| Return: | (HRESULT) status | S\_OK if successful |
