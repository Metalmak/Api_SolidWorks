# Sketch::GetLineCount

This method is obsolete and has been superseded
by Sketch::GetLineCount2.

Description

This method gets the line count
in the sketch.

Syntax (OLE Automation)

retval = Sketch.GetLineCount ()

|  |  |  |
| --- | --- | --- |
| Return: | (long) retval | Number of lines in the sketch |

Syntax (COM)

status = Sketch->GetLineCount (
&retval )

|  |  |  |
| --- | --- | --- |
| Output: | (long) retval | Number of lines in the sketch |
| Return: | (HRESULT) status | S\_OK if successful |
