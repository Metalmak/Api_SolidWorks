# PropertyManagerPage2Handler Object

This
object and its methods and properties are obsolete and have been superseded
by [PropertyManagerPage2Handler2](../PropertyManagerPage2Handler2/PropertyManagerPage2Handler2.htm).

![image\IPropertyManagerPageHandler_h.gif](../image/PropertyManagerPage2Handler_h.gif)

Must be implemented by the add-in application to
interact with a PropertyManagerPage2.

For all unimplemented methods of this object, the
add-in application can return E\_NOTIMPL.
