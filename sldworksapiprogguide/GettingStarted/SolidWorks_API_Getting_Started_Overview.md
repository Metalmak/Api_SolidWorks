# SOLIDWORKS API Help

# SOLIDWORKS API Getting Started Overview

The SOLIDWORKS API SDK contains all of the functionality you need to develop SOLIDWORKS API applications.

### To install the SOLIDWORKS API SDK:

1. Ensure that Microsoft Visual Studio is installed in **c:\Program Files**.
2. Copy **\apisdk\SolidWorks API SDK.msi** from
   the installation media to a local directory.

 - or -

 Download the SOLIDWORKS API SDK installer from the SOLIDWORKS
Customer Portal:

1. Log into
   [customerportal.solidworks.com](http://customerportal.solidworks.com).
2. In the Download section, click **Downloads and Updates**.
3. On the Downloads page:

   1. At the top, select the version
      of SOLIDWORKS whose API SDK you want to download.
   2. On the SOLIDWORKS tab, click the product link for the service pack whose API
      SDK you want to download.
4. In the SOLIDWORKS Download EULA page, click the **English** button
   and click Accept
   Agreement & Continue.
5. At the bottom of the Download and Install SOLIDWORKS Products Using
   the Installation Manager page, click the **manual download method** link.
6. On the Manual Installs page, select a version in the Upgrading
   from Service Pack list, select the product in the
   SOLIDWORKS
   Product list, and click Continue.
7. On the Manual Download Packages page, click SOLIDWORKS
   API SDK in the Step 5 - Optional
   updates table to download the API SDK to a local directory.

3. Double-click **apisdk.exe** or **SolidWorks API SDK.msi** to run
   the API SDK InstallShield Wizard.

Prior to developing SOLIDWORKS API applications, you should be familiar
with using the SOLIDWORKS software interactively and programming in the
languages that you intend to use. If you are not, then you should:

* Complete the SOLIDWORKS online tutorials, including
  the SOLIDWORKS API tutorials. Click Help
  > SOLIDWORKS Tutorials to
  access the tutorials.
* Attend [SOLIDWORKS
  training courses offered at SOLIDWORKS Authorized Training and Support
  Centers](http://www.solidworks.com/pages/services/Training/training.html).
* Take courses in the [programming
  languages](SolidWorks_API_Standalone_and_Add-in_Applications_Overview.htm) that you intend to use.
