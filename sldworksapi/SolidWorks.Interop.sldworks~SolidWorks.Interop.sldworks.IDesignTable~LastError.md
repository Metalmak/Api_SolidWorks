#### Property Value

Last error that occured in this design table as defined in swDesignTableErrors\_e

# ![](dotnetimages/collapse.gif)Visual Basic for Applications (VBA) Syntax

See DesignTable::LastError.

# ![](dotnetimages/collapse.gif)Remarks

Getting this property returns the last error generated by a request to modify the design table. Setting this property allows you to clear the last design table error that occurred.
