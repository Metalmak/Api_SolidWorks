Obsolete for documents created in SOLIDWORKS 2016 and later. Relocates the offset (origin) of the specified piece of text in a compound note.

# ![](dotnetimages/collapse.gif)Remarks

Because a compound note can have multiple pieces of text, many of the compound note methods require you to specify the index value of the desired text. For example, the first piece of text added to the compound note using [INote::AddText](SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.INote~AddText.html) has index number of 1, the second text added has an index number of 2, and so on.

This method does not support standard notes.
