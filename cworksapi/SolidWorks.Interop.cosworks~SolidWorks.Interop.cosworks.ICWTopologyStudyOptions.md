# ![](dotnetimages/collapse.gif)Remarks

The methods of this interface correspond to elements found on the tabs of the Topology dialog that appears when you select ***topology\_study*** **RMB > Properties** in the FeatureManager design tree.

See the **Topology Options** topic in the Simulation user-interface help for more information.
