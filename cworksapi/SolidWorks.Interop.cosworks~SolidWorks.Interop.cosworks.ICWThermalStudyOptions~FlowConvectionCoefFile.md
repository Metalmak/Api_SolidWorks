#### Property Value

Full path name of the result file generated by SOLIDWORKS Flow Simulation (**\*.fld**)

# ![](dotnetimages/collapse.gif)Visual Basic for Applications (VBA) Syntax

See CWThermalStudyOptions::FlowConvectionCoefFile.

# ![](dotnetimages/collapse.gif)Remarks

This property is valid only if [ICWThermalStudyOptions::CheckFlowConvectionCoef](SolidWorks.Interop.cosworks~SolidWorks.Interop.cosworks.ICWThermalStudyOptions~CheckFlowConvectionCoef.html) is set to 1.
